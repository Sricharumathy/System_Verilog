# 6. Write a associative array example .explain its functionality.
### An associative array in SystemVerilog is a dynamically allocated, sparse array whose elements are indexed using a specific index data type,
### rather than a fixed integer range. It is useful for storing data when the number of elements is unknown or when the index values are non-contiguous
### or not known in advance.Unlike a dynamic array, an associative array does not require memory to be allocated for every possible index.
### Memory is allocated only for the elements that are actually assigned.<br>

# Syntax---->    data_type array_name[index_type];
